# Frontier Tech Research

一个面向开放协作的前沿技术研究仓库，聚焦于**可验证的研究线索、轻量实验和工程化复现**。仓库不追求追逐每一条热点，而是记录问题、假设、方法、结果与局限，帮助读者从资讯发现逐步走向可复现实验。

> 研究声明：这里的内容是探索性材料，不构成投资、商业、医疗或安全建议。涉及高风险技术时，优先讨论安全边界、可控性、隐私和社会影响。

## 当前重点研究方向

### 1. AI 与智能体

多模态模型、推理与长上下文；Agent 架构、工具调用、记忆和多智能体协作；RAG、评测、数据质量与模型可解释性；小模型、边缘推理、效率优化和合成数据；AI 安全、对齐、红队测试与隐私保护。

### 2. Web3、密码学与去中心化系统

零知识证明、可验证计算和隐私增强技术；去中心化身份、可验证凭证和数据主权；智能合约安全、形式化验证与跨链机制；去中心化物理基础设施（DePIN）和去中心化自治组织。在不鼓励投机的前提下，研究区块链的协议设计与实际应用。

### 3. 量子计算

量子纠错、容错计算和噪声缓解；量子算法、量子机器学习与混合量子-经典工作流；超导、离子阱、光量子等硬件路线的工程约束；后量子密码学与密码迁移准备。

### 4. 机器人与具身智能

视觉-语言-动作模型和世界模型；灵巧操作、导航、仿真到现实迁移；人机协作、家庭机器人与安全评测；低成本硬件、开源控制栈和可重复实验。

### 5. 其他交叉方向

新型能源、材料与气候技术；生物计算与计算生物学（仅限公开、合规的计算研究）；空间技术、先进制造与边缘计算；隐私计算、可信硬件与数字公共基础设施。

## 自动资讯工作流

`.github/workflows/collect-frontier-tech.yml` 会在每周一 08:00 UTC（北京时间 16:00）定时运行，也支持在 GitHub Actions 中手动触发。修改采集脚本或工作流后也会自动运行。

工作流执行 `src/collect_news.py`，从公开 RSS/Atom 源收集 AI、量子计算、机器人和密码学/Web3 方向的研究线索，并更新 [`data/frontier-tech-news.md`](data/frontier-tech-news.md)。如果有变化，GitHub Actions 会以 `github-actions[bot]` 身份自动提交。资讯摘要用于发现线索，自动化不会替代人工核验；后续可加入来源白名单、去重、质量评分、邮件通知和人工审核门槛。

## 目录结构

```text

├── docs/                          # 研究方法、评测规范和专题笔记
├── experiments/
│   └── ai-frontier-radar/         # 第一个可复现实验

│       └── radar.py
├── src/
│   └── collect_news.py             # RSS/Atom 采集器
└── README.md
```

## 快速开始

环境要求为 Python 3.10+，项目仅使用标准库：

```bash
python src/collect_news.py --output data/frontier-tech-news.md
python experiments/ai-frontier-radar/radar.py
```

第一个实验是一个无需模型、无需外部依赖的关键词基线，对资讯摘要中的研究线索进行可解释的粗粒度分类和排序。它不是事实核验器，也不应替代人工阅读。

## 研究记录规范

每个实验建议包含问题、假设、数据与环境、方法、结果、失败记录、局限与下一步。请明确数据来源、版本、硬件和依赖；报告不确定性；避免将小样本结果外推为普遍结论。

## 协作方式

欢迎提交 Issue 分享研究问题、公开数据集、复现实验或文献线索，也欢迎提交 Pull Request 改进代码和文档。涉及安全、隐私或潜在滥用的内容，请在提交前明确威胁模型、使用边界和负责任披露方式。
