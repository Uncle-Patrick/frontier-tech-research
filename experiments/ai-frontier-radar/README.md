# AI Frontier Radar：可解释的研究线索基线

这是仓库的第一个实验，用一个无需模型、无需外部依赖的关键词基线，对资讯摘要中的研究线索进行粗粒度分类和排序。

## 为什么从基线开始

前沿技术追踪很容易直接跳到大模型分类器，但一个透明的基线有三个价值：

1. **可复现**：任何人都可以用 Python 标准库运行。
2. **可解释**：每个标签都能追溯到命中的关键词。
3. **可比较**：后续可以用 embedding、LLM 或人工标注结果与它对比。

## 运行

在仓库根目录执行：

```bash
python experiments/ai-frontier-radar/radar.py
```

脚本默认读取 `data/frontier-tech-news.md`，输出带有主题标签和命中次数的研究线索。它不是事实核验器，也不应替代人工阅读。

## 下一步实验

- 建立 100 条人工标注的评测集，报告 precision、recall 和 macro-F1。
- 增加同义词、否定词和短语级匹配，减少关键词误报。
- 与小型 embedding 检索或本地模型分类器比较成本和效果。
- 对重复论文、转载内容和来源质量加入去重及加权策略。
